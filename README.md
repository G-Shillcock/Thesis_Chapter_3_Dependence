# Chapter 3 – The Evolution of Mutual Dependence

**George Shillcock**  
Department of Biology, University of Oxford

## Overview

This repository contains the mathematical models, numerical simulations, and analysis code associated with Chapter 3 of my doctoral thesis at the University of Oxford.

The chapter investigates the coevolution of reproductive specialisation and mutual dependence in social insects. Specifically, it examines the conditions under which helpers evolve lifetime sterility and breeders become dependent on helpers for reproduction.

The model uses kin-selection theory to investigate how relatedness, survival, group size, and reproductive trade-offs influence the evolution of complete joint specialisation.

## Contents

The repository contains Python notebooks used to:

- Calculate selection gradients for helper and breeder specialisation.
- Analyse evolutionary stability and coevolutionary dynamics.
- Derive and evaluate analytical conditions for complete joint specialisation.
- Numerically classify evolutionary outcomes.
- Investigate parameter sensitivity.
- Generate figures.

## Requirements

The analyses use Python and the following libraries:

- NumPy
- SciPy
- SymPy
- Matplotlib

## Usage

The notebooks can be run using Jupyter Notebook or Google Colab.
